# SmartSearch AI: Web Crawler Module

This directory contains the crawling pipeline, Scrapy spiders, rate-limiting policies, and HTML sanitation components.

## Planned Structure (Phase 4):
- `spiders/`: Scrapy crawler definitions
- `pipelines.py`: Content extraction, cleaning, and indexing pipelines
- `middlewares.py`: User-Agent rotation and polite rate-limiting
- `settings.py`: Concurrency and robot etiquette configuration
