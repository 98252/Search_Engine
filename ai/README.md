# SmartSearch AI: AI & ML Module

This directory manages neural embedding generation, vector distance metrics, re-ranking models, and query expansion.

## Planned Structure (Phase 3):
- `embeddings.py`: Sentence-Transformers integration (`all-MiniLM-L6-v2`)
- `chunker.py`: Recursive token text segmentation with context overlap
- `reranker.py`: Reciprocal Rank Fusion (RRF) & cross-encoder ranking
